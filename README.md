# Dash-Snatch

A location-based mobile photo game where players hunt, photograph, and track a mysterious character named Dash Bottenberg across the world.

## 🎮 Game Concept

**Dash-Snatch** is an interactive, location-based game that combines photography with gamification:

- **Photograph Dash Bottenberg** to earn XP and climb the ranks
- **Gain rewards** based on photo quality and rank progression
- **Tag locations** where photos are taken to build a community map
- **Leaderboards** showcase top hunters and most-visited locations
- **Different ranks** unlock as you accumulate XP
- **Zero XP** for photographing anyone/anything other than Dash

## 🎯 Core Features

### Photography System
- Capture photos of Dash Bottenberg in various locations
- AI/manual validation to confirm the subject
- Quality-based ranking (Common, Uncommon, Rare, Epic, Legendary)
- XP rewards vary by rank quality

### Location Tracking
- Tag GPS coordinates where Dash was photographed
- Build a heatmap showing Dash's movement patterns
- Community map shows all sightings in real-time or with delay
- Discover popular Dash hotspots

### Progression System
- Earn XP from valid photographs
- Unlock new ranks as XP increases
- Track personal statistics (photos taken, total XP, rank level)
- Compete on global leaderboards

### User Profiles
- Personal profile with photo history
- Rank progression and achievements
- Most frequent locations visited
- Social features (follow other hunters)

## 📱 Tech Stack (Planned)

- **Frontend:** React Native / Flutter (Mobile-first)
- **Backend:** Node.js + Express / Python Flask
- **Database:** PostgreSQL / MongoDB
- **Maps:** Google Maps API / Mapbox
- **Image Recognition:** TensorFlow / Cloud Vision API
- **Real-time:** WebSockets for live map updates
